# LanShare

局域网内任意设备都能访问的文件传输与共享页面。零运行时依赖，只要求 Node.js ≥ 22.5。

## 启动

```bash
chmod +x start.sh && ./start.sh
```

或者直接：

```bash
node server.js
```

启动后终端会打印可访问地址：

```
本地:   http://localhost:8090
局域网: http://192.168.210.53:8090   (enp49s0)
```

把局域网地址发给手机、平板或另一台电脑即可。分享功能生成链接和二维码时也会自动使用这个局域网 IP，而不是 `localhost`。

## 常用参数

| 方式 | 说明 |
| --- | --- |
| `--port 8090` | 端口 |
| `--root /path/to/dir` | 共享哪个目录（默认 `./files`） |
| `--name "我的电脑"` | 页面左上角显示的设备名 |
| `--host 0.0.0.0` | 监听地址 |

也可以使用环境变量：`PORT`、`LANSHARE_ROOT`、`LANSHARE_NAME`、`LANSHARE_MAX_UPLOAD`。

```bash
LANSHARE_ROOT=~/Downloads PORT=9000 node server.js
```

## 功能

- **文件管理**：浏览、新建文件夹、重命名、移动（拖到文件夹上）、删除、批量操作
- **上传**：拖拽、点选、选择整个文件夹；4 MB 分片 + 3 并发 + 失败重试，大文件不占内存
- **下载**：单文件直传，支持 Range（视频可拖动进度条）；多选或文件夹自动流式打包 ZIP
- **预览**：图片、视频、音频、PDF、文本直接在页面内查看
- **分享**：生成局域网链接与二维码，扫码即可在手机上打开下载页
- **多端适配**：手机、平板、桌面三套布局；深色 / 浅色主题
- **实时刷新**：其他设备上传后当前页面自动更新（SSE）

## 安全说明

这是**给自己用的局域网工具**，默认没有登录和权限控制：

- 同一网络内的人打开地址即可读写你的共享目录
- 只在自己信任的 Wi-Fi / 有线网络里运行，不要直接暴露到公网
- 如需公网访问，请放在反向代理和认证之后

路径参数在服务端做了规范化与越界检查，`.lanshare` 内部目录不可访问。

## 关于开源方案

做选型时对比过几个成熟项目：

| 项目 | 为什么没有直接用 |
| --- | --- |
| LocalSend | 需要在每台设备装客户端，不是网页 |
| PairDrop / ShareDrop | WebRTC 点对点，没有服务端存储，关页面就没了 |
| File Browser | 目录管理强，但界面偏旧，没有分片续传与分享二维码 |
| copyparty | 功能极全，配置项多，界面风格偏工程师向 |
| dufs | 很轻，但缺少分享页、二维码、实时刷新 |

LanShare 保留了它们最有用的部分：分片流式上传、Range 下载、流式 ZIP、局域网分享，界面按手机到桌面的多端适配重做。
